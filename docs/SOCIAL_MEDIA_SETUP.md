# Social Media Provider Setup Guide

This guide details how to configure the supported social media providers for AffeXAI/Cortex.

## 1. LinkedIn
**Status**: Configured (Feb 18, 2026)

### Prerequisites
- LinkedIn Developer App (https://www.linkedin.com/developers/apps)
- Products added: **Sign In with LinkedIn**, **Share on LinkedIn**

### Configuration (`.env`)
```bash
LINKEDIN_CLIENT_ID=your_client_id
LINKEDIN_CLIENT_SECRET=your_client_secret
```

### Redirect URI
`http://localhost:9003/affexai/admin/social/accounts` (Adjust tenant slug as needed)

## 2. Facebook & Instagram (Meta)
**Status**: Configured (Feb 18, 2026)

### Prerequisites
- Meta for Developers App (https://developers.facebook.com/)
- App Type: **Business**
- Permissions: `pages_manage_posts`, `pages_read_engagement`, `instagram_basic`, `instagram_content_publish`

### Configuration (`.env`)
```bash
FACEBOOK_APP_ID=your_app_id
FACEBOOK_APP_SECRET=your_app_secret
```

### Redirect URI
`http://localhost:9003/affexai/admin/social/accounts`

## 3. Twitter (X)
**Status**: Active

### Configuration (`.env`)
```bash
TWITTER_CLIENT_ID=...
TWITTER_CLIENT_SECRET=...
TWITTER_BEARER_TOKEN=...
```

## Troubleshooting
- **"Client ID not configured"**: Ensure `.env` is updated AND the backend server has been restarted.
- **Redirect URI Mismatch**: Ensure the URL in the developer portal exactly matches the one generated by the frontend.
