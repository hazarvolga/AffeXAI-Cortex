# AffeXAI User Guide

Welcome to the AffeXAI Administration Panel. This guide will help you navigate the features and manage your tenant effectively.

## 🚀 HQ Dashboard (Command Center)
**Route:** `/admin/command-center`

The HQ Dashboard is your central hub for monitoring system health, AI agent performance, and quick actions.

### Key Features
*   **System Status:** Real-time metrics on server load, email engagement, and brand sentiment.
*   **Neural Insights:** AI-driven opportunities and anomaly detection (e.g., "New Trend Detected", "Sentiment Spikes").
*   **AI Config Shortcut:** Quick access to configure the `AiCoPilot` and other AI settings.
*   **Recent Activity:** A feed of the latest actions taken within your tenant.
*   **Performance Timeline:** Visual graph of interactions vs. conversions over the last 7 days.

## 📱 Social Media Management
**Route:** `/admin/social`

Manage your social presence across platforms like Twitter, LinkedIn, and Instagram.

*   **Create Deployment:** Compose and schedule posts.
*   **Signal Registry:** View all scheduled, published, and drafted posts.
*   **Analytics:** Track engagement (Likes, Shares, Reach) and Sentiment Analysis.

## 📧 Email & Marketing
**Route:** `/admin/email`

*   **Campaigns:** Create and manage email marketing campaigns.
*   **Subscribers:** Manage your contact lists and segmentation.

## 🛠️ Settings & Configuration
*   **AI Settings:** `/admin/ai-settings` - Configure LLM providers and agent behaviors.
*   **General Settings:** `/admin/settings` - Tenant profile and preferences.

## ❓ Support & Help
**Route:** `/admin/support`

Access documentation, file support tickets, and view FAQs.
